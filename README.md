# 교실 토마토 연구소

학생이 토마토를 돌보고 변화를 관찰·기록하는 교실 정원 시뮬레이션입니다.

## 교육 중심 설계
- 꾸미기는 별을 모으거나 성장 조건을 달성하지 않아도 처음부터 사용할 수 있습니다.
- 학생 화면에서는 획득 점수보다 발견·돌봄에 대한 문장 피드백을 보여줍니다.
- 성장 앨범에서 첫 사진과 최근 사진을 비교합니다.
- 관찰 기록은 변화와 그 근거, 돌봄을 하거나 하지 않은 까닭을 중심으로 작성합니다.
- 잘 자라지 않거나 변화가 없는 날도 관찰의 일부로 다룹니다.

## 실행과 확인
정적 웹페이지 `index.html`을 제공합니다. `node verify-learning.cjs`로 교육 중심 변경의 핵심 동작을 확인할 수 있습니다.

## 디자인 에셋
`assets/classroom-2-5d/preview.html`에서 확정 교실 배경과 캐릭터·성장 단계·화분을 볼 수 있습니다.
`game-art.js`가 배경과 투명 시트를 실제 교실·캐릭터 선택·화분 화면에 연결합니다. 남학생/여학생 방향별 이미지, 6종 화분, 성장 이미지와 돌봄 도구를 사용합니다. 배경에 맞춘 책상 충돌 영역, 클릭 경로 탐색과 책상 가림 처리를 포함합니다. 연속 걷기 프레임 대신 방향별 이미지와 가벼운 보행 움직임을 사용합니다. 꽃봉오리·익어가는 열매·고사 상태는 정확한 생육 표현을 위해 기존 렌더러를 유지합니다.
기존 저장 데이터의 별 수치는 호환성을 위해 남겨두지만 꾸미기 구매에 사용하지 않습니다.
